# Color System Guide (Web Design)

## 1. Core Structure

Define colours by **role**, not preference.

- **Primary**
  - Main brand colour
  - Used for key actions, links, highlights

- **Secondary**
  - Supports the primary
  - Adds variation without competing

- **Accent**
  - Used sparingly for emphasis (e.g. buttons, alerts)
  - High contrast with primary

- **Neutral**
  - Backgrounds, text, structure
  - Typically whites, greys, off-whites

---

## 2. Colour Ratios

Maintain visual balance using a simple ratio:

- **60%** → Neutral (background)
- **30%** → Primary / Secondary
- **10%** → Accent

Guideline:
- Accents should be **rare and intentional**
- Neutrals do most of the work

---

## 3. Colour Shades (System)

Each core colour should have a range of shades:

- **Light (100–200)**
  - Backgrounds, subtle highlights

- **Base (400–600)**
  - Main usage (buttons, links)

- **Dark (700–900)**
  - Text, strong emphasis

Example:
- Blue-100, Blue-500, Blue-900

This ensures consistency across the UI.

---

## 4. Light Mode & Dark Mode

Design with both modes in mind from the start.

### Light Mode
- Background: white or off-white (e.g. eggshell)
- Text: dark grey (avoid pure black)
- Accents: slightly muted for readability

### Dark Mode
- Background: dark grey (avoid pure black)
- Text: light grey (not pure white)
- Accents: slightly brighter to maintain contrast

### Key Principle
- **Invert contrast, not colours**
  - Preserve meaning across modes
  - Ensure readability in both

---

## 5. Building a Palette (Practical Method)

### Step 1: Define intent
- Serious vs playful  
- Traditional vs modern  
- Calm vs energetic  

---

### Step 2: Choose a primary colour
- Sets tone and identity

---

### Step 3: Add neutrals
- Background + text colours
- These dominate the interface

---

### Step 4: Add an accent
- For interaction and emphasis
- Must contrast clearly

---

### Step 5: Create shade variants
- Light, base, dark for each key colour

---

## 6. Example Palette (Balanced & Readable)

### Light Mode
- Background: off-white (eggshell)
- Text: dark grey
- Primary: muted blue
- Secondary: cool grey
- Accent: soft blue or subtle gold

### Why it works
- High readability (neutral-heavy)
- Blue conveys trust and stability
- Muted tones reduce visual fatigue
- Accent draws attention without overwhelming

---

## 7. Accessibility Guidelines

- Ensure sufficient contrast:
  - **4.5:1** for body text
  - **3:1** for large text

- Do not rely on colour alone:
  - Combine with icons, labels, or patterns

- Avoid problematic combinations:
  - Red / green
  - Low-contrast tones

---

## 8. Common Mistakes

- Using too many colours
- No clear role for each colour
- Low contrast text
- Overusing bright or saturated colours
- Using pure black (#000) or pure white (#FFF) everywhere
- Designing only for light mode (ignoring dark mode)

---

## 9. Rules of Thumb

- Start simple:
  - White / off-white
  - Dark grey text
  - One primary colour
  - One accent colour

- Use colour to:
  - Guide attention
  - Indicate interaction
  - Reinforce hierarchy

- If everything is colourful:
  - Nothing stands out

- Prioritise:
  - Readability
  - Consistency
  - Restraint

---

## 10. Summary

- Colour is a **system**, not decoration
- Define roles and stick to them
- Use ratios to maintain balance
- Support both light and dark modes
- Keep palettes minimal and intentional
- Optimise for readability first, aesthetics second
