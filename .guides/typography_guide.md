# Typography & Layout Guide (Web: Desktop + Mobile)

## Core Principles
- Use **max 2 fonts** with clear roles
  - Serif → authority, long-form, emphasis
  - Sans-serif → clarity, UI, readability
- Prioritise **spacing, hierarchy, and layout** over font choice
- Ensure **clear visual hierarchy** (headings, subheadings, body)
- Keep layouts **simple and consistent**

---

## Font Pairing
- Combine **serif (headlines/emphasis)** + **sans-serif (body/UI)** for balance
- Alternatively: use a single sans-serif family with multiple weights

### Recommended Google Fonts
- Inter (sans-serif) + Merriweather (serif)
- Source Sans 3 (sans-serif) + Playfair Display (serif)
- Lato (sans-serif) + Libre Baskerville (serif)

---

## Typography Scale

### Desktop
- Body: `16–18px`
- H1: `28–36px`
- H2: `22–28px`
- H3: `18–22px`

### Mobile
- Body: `16–18px` (do not reduce)
- H1: `24–30px`
- H2: `20–24px`
- H3: `18–20px`

---

## Line Length
- Optimal: **60–75 characters per line (desktop)**
- Mobile: naturally shorter (~30–40 characters), acceptable

---

## Line Height (Leading)
- Desktop: `1.5 – 1.6`
- Mobile: `1.6 – 1.8`

---

## Font Weight
- Body: `400`
- Subheadings: `500–600`
- Headings: `600–700`
- Use bold sparingly

---

## Spacing System

### Base Unit
- Use an **8px spacing system**

### Common Values
- Small gap: `8px`
- Paragraph spacing: `16–24px`
- Section spacing: `32–48px`
- Large separation: `64px+`

---

## Layout

### Desktop
- Content width: `600–750px`
- Use generous margins
- Optional: multi-column layouts (used carefully)

### Mobile
- Single-column layout only
- Side padding: `16–20px`
- Remove sidebars and non-essential elements

---

## Paragraph & Content Structure
- Keep paragraphs short (3–5 lines)
- Add clear spacing between paragraphs
- Use headings frequently to break content
- Left-align text (avoid justified text)

---

## Visual Hierarchy
- Ensure clear differences in:
  - Size
  - Weight
  - Spacing
- Avoid subtle differences that are hard to distinguish

---

## Responsive Considerations
- Do not scale text down for mobile
- Increase spacing for readability on smaller screens
- Optimise for scanning:
  - shorter paragraphs
  - clear sections
  - consistent rhythm

---

## Summary
- Good typography is driven by **spacing, hierarchy, and consistency**
- Serif and sans-serif combinations are effective when roles are clearly defined
- Mobile requires **more spacing, not less**
- Keep layouts simple and prioritise readability
