# Layout & Design System (Minimal Web Design)

## 1. Core Philosophy

- Clarity over decoration  
- Consistency over creativity  
- Spacing over complexity  
- Function over flair  

Guideline:
- Every element must serve a purpose (structure, hierarchy, or flow)
- Remove anything that does not contribute

---

## 2. Layout System

### Content Width
- Standard reading width: `600–750px`
- Wide layouts (e.g. landing pages): up to `1200px`

---

### Alignment
- Default: **left-aligned**
- Use center alignment only for:
  - Hero sections
  - Short text blocks

---

### Grid
- Mobile: **single column**
- Desktop: **1–3 columns max**
- Avoid complex grid systems

---

### Sections
- Desktop padding: `64–96px` (top and bottom)
- Mobile padding: `32–48px`

- Each section should:
  - Be visually distinct
  - Have consistent spacing

---

## 3. Spacing System

### Base Unit
- Use an **8px spacing system**

### Scale
- `8 / 16 / 24 / 32 / 48 / 64`

### Usage
Apply consistently to:
- Margins
- Padding
- Gaps between elements

---

## 4. Tiles / Cards

### Structure
- Padding: `16–24px`
- Border radius: `8–12px`
- Background: slightly elevated from page background

---

### Separation
Use one or both:
- `1px` light border
- Soft shadow

---

### Content Structure
- Title
- Supporting text
- Optional action (button/link)

---

### Interaction
- Hover (desktop):
  - Slight elevation (shadow increase)
  - Subtle feedback only

---

## 5. Shape Language

### Border Radius
- Standard: `8px`
- Larger elements: `12px`

### Rule
- Use consistent radius across:
  - Buttons
  - Cards
  - Inputs

---

## 6. Depth & Shadows

### Principles
- Use sparingly
- Prefer soft, diffused shadows

---

### Elevation Levels
- Base: no shadow
- Raised: subtle shadow
- Modal: slightly stronger shadow

Limit to **2–3 levels**

---

## 7. Lines & Dividers

### Style
- Thickness: `1px`
- Colour: light neutral

---

### Usage
- Separate sections
- Group related content

Avoid:
- Heavy borders
- Overuse of dividers

---

## 8. Typography Integration

- Left-align body text
- Maintain clear spacing between elements

### Spacing Rule
- More space **before headings** than after

---

## 9. Interaction Principles

### Hover / Focus
- Subtle only:
  - Slight colour change
  - Shadow adjustment
  - Underline for links

---

### Clickable Elements
- Must be:
  - Clearly identifiable
  - Consistent in style

---

## 10. Visual Rhythm

Maintain consistent flow:

- Section → spacing → content → spacing → next section

Guideline:
- Avoid irregular spacing patterns
- Consistency creates perceived quality

---

## 11. Design Characteristics (Minimal Style)

Inspired by modern minimal design principles:

- Generous whitespace
- Limited colour usage
- Soft edges
- Strong hierarchy
- Content-first layout
- Minimal visual noise

---

## 12. Common Mistakes

- Inconsistent spacing
- Overuse of shadows
- Mixing multiple border styles
- Excessive center alignment
- Too many layout variations
- Trying to fill empty space unnecessarily

---

## 13. Rules of Thumb

- Keep layouts simple and predictable
- Use spacing to create structure
- Limit visual elements
- Maintain consistency across all components
- Prioritise readability and clarity

---

## 14. Summary

- Layout is driven by **spacing, structure, and consistency**
- Use a simple grid and constrained widths
- Keep components minimal and uniform
- Apply depth and lines sparingly
- Design for clarity, not decoration
